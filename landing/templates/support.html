01. 먼저 확인

연결 가이드에서 ChatGPT Work·Claude MCP, 에이전트 Skill, Rust CLI와 self-hosting 절차를 확인하세요. 서비스 상태는 health endpoint에서 확인할 수 있습니다.

02. 도움 요청

재현 가능한 버그, 설치 문제와 기능 제안은 공개 GitHub Issues에 남겨주세요. 사용한 Vibe Memory 버전, 실행 환경, 재현 단계와 민감정보를 제거한 오류 메시지를 포함하면 확인에 도움이 됩니다.

취약점이 아닌 일반 문의에는 별도 응답 시간 보장이 없습니다. 오픈소스 사용자는 저장소의 문서와 이슈 내역도 함께 확인해 주세요.

03. 보안 문제

공개 전에 조율해야 하는 취약점은 이슈에 게시하지 말고 보안 정책의 비공개 신고 절차를 사용하세요. 이미 노출된 키는 먼저 해당 연결을 철회하고 새 키를 발급하세요.
